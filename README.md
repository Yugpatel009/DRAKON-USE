# 🐉 DRAKON AI — Next-Gen Coding Assistant

**DRAKON** is a powerful, AI-driven coding assistant built on the **Zenith Architecture**. It seamlessly blends the speed of cloud-based inference with the privacy of local large language models, giving developers a flexible and future-proof development companion.

> ⚡ Fast when you need it  
> 🔐 Private when it matters  
> 🧠 Smart where it counts  

![DRAKON UI](static/img/logo.png)

---

## ✨ Key Features

### 🧠 Dual-Engine Intelligence
- 🚀 **Cloud Speed**  
  Powered by **Groq’s LPU inference engine** using **Llama 3.3 70B** for ultra-low-latency responses.
- 🔒 **Local Privacy**  
  Seamless **Ollama** integration to run models like **Llama 3**, **Mistral**, and **Gemma** entirely on your machine.

### 🎨 Visual Creativity
- Built-in **ComfyUI** integration for high-quality image generation directly within the chat interface.

### 🖥️ Modern Interface
- Sleek **dark-mode UI** inspired by Groq  
- Glassmorphism design  
- Smooth animations and responsive layout

### 🧠 Context-Aware Conversations
- Intelligent chat history and context management for long-running, coherent coding sessions.

### 🔐 Secure Authentication
- Robust user authentication powered by **Firebase Auth**.

### 💬 Chat Management
- Save, rename, and organize chats to keep your workflow clean and efficient.

## 🎮 Usage

### 💬 Chatting
- **Guest Mode**  
  Try DRAKON with limited prompts.
- **Authenticated Mode**  
  Sign up or log in to unlock full chat history and features.
- **Model Switching**  
  Click the model name in the header to switch between:
  - ☁️ Cloud (Groq)
  - 💻 Local (Ollama)

### 🖼️ Image Generation
- Ensure **ComfyUI** is running (or allow auto-start if configured).
- Select **Image Gen** mode or use supported image prompts in chat.
